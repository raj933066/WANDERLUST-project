# ✈️ Wanderlust

Wanderlust is a full-stack web application inspired by Airbnb. It allows users to create, view, and review listings for accommodations around the world.

## 🚀 Tech Stack

**Frontend:**
- HTML5, CSS3, JavaScript
- EJS (Embedded JavaScript templates)
- Bootstrap (for styling)

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB (using Mongoose)

## ✨ Key Features
*(Note: You can update this list as you build more)*
- **CRUD Operations:** Users can Create, Read, Update, and Delete listings.
- **Responsive Design:** Works on mobile and desktop.
- **Database Integration:** Listings are stored persistently in MongoDB.
- *(Planned)* **User Authentication:** Sign up and login functionality.
- *(Planned)* **Reviews System:** Users can leave ratings and comments.
- *(Planned)* **Map Integration:** View listing locations on a map.
